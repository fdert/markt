# مسح نظام نقاط سعد (SAAED POS) ومقارنته برصيد

تم المسح على تطبيق Windows الإصدار 4.1.9 (419): لوحة التحكم، نافذة البيع، الدفع، الإعدادات بكل أقسامها، الأجهزة المرتبطة، المنتجات، المخزون، العملاء والموردين، السجل والتقارير، قارئ الفاتورة الإلكترونية، المنيو الذكي، ومتجر الإضافات.

## ما وُجد في نقاط سعد

| القسم | المزايا |
|---|---|
| نافذة البيع | نوع الطلب (محلي / سفري / توصيل)، المفضلة، التصنيفات، البحث بالاسم والباركود، لوحة مفاتيح على الشاشة، العميل، اختيار الطاولة، الملاحظات، الخصم (نسبة/مبلغ)، مجموعات الأسعار، أنظمة الولاء (داخلي + LoyaPro + بونات)، تعليق الفاتورة، **تقريب الفاتورة** |
| الدفع | نقدي، بطاقة، SAEEDPAY، جيديا، تابي/تمارا، هنقرستيشن، جاهز، تو يو، نينجا، واصل، دفع أونلاين، الدفع المتعدد، الدفع من محفظة العميل |
| إعدادات الطباعة | الطباعة التلقائية عند الإنشاء / التعليق / الإرجاع، طباعة عدد وكمية المنتجات، طباعة طرق الدفع، اسم الفرع كعنوان للفاتورة، تنبيه تعديل فاتورة معلقة قبل الطباعة |
| الأجهزة المرتبطة | طابعة رئيسية + طابعات طلبات لكل قسم مطبخ، شاشات مطبخ، اتصال: Wi‑Fi (IP:9100)، بلوتوث، USB، خادم HTTP |
| شاشة المطبخ | إرسال الطلب عند الإنشاء أو التعليق |
| نقطة البيع | الدفع المتعدد، الكسور في الكمية، عرض رقم الطلب، مزامنة فورية |
| أخرى | شاشة العميل (متصلة / خارجية / VFD)، الطلبات الخارجية، **اختصارات لوحة مفاتيح قابلة للتخصيص**، وضع ECR لأجهزة الدفع |
| المنتجات | صورة، أماكن التوفر (فروع)، باركود بالكاميرا، وحدات، تصنيف، الضريبة المطبقة، سعر البيع والشراء، شامل الضريبة |
| المخزون | فترات جرد لكل فرع، تحويل المخزون، المخزون التالف |
| العملاء | فرد / مؤسسة، الاسم، الجوال، الرقم الضريبي |
| التقارير | يومي / أسبوعي / شهري / سنوي مع تفصيل طرق الدفع، طباعة ومشاركة |
| أدوات | قارئ QR الفاتورة الإلكترونية، المنيو الذكي (QR) |
| متجر الإضافات | جاهز، واتساب، سلة، توقيت الطاولات، طباعة التذاكر، طلب من الطاولة QR، الولاء والمحفظة، المنيو الإلكتروني، المحاسبة، الجرد، فرع إضافي، المرحلة الثانية لزاتكا، قيود، التصنيع، الجيم، الخياطة |

## الفجوات التي أُضيفت إلى رصيد

| الميزة | الحالة |
|---|---|
| نوع الطلب: محلي / سفري / توصيل | ✅ |
| الطاولات (إدارة واختيار في الكاشير) | ✅ |
| تقريب الفاتورة (لأقرب 0.25 / 0.5 / 1 ريال) | ✅ |
| مجموعات الأسعار (جملة، موظفين…) | ✅ |
| رقم الطلب اليومي على الإيصال | ✅ |
| شاشة المطبخ (KDS) وتذاكر المطبخ لكل قسم | ✅ |
| خيارات الطباعة التلقائية (إنشاء / تعليق / إرجاع) وعدد القطع وطرق الدفع | ✅ |
| شاشة العميل (نافذة ثانية تعرض السلة والإجمالي) | ✅ |
| اختصارات لوحة مفاتيح قابلة للتخصيص | ✅ |
| تفعيل/منع الكسور في الكمية | ✅ |
| محفظة العميل (رصيد مسبق الدفع، شحن ودفع) | ✅ |
| طرق دفع مخصصة (تطبيقات التوصيل، تابي، تمارا، جيديا…) مع تقاريرها | ✅ |
| المنتجات المفضلة في الكاشير | ✅ |
| جلسات الجرد بفترات وفروقات واعتماد | ✅ |
| المخزون التالف (سجل وإضافة) | ✅ |
| قارئ QR الفاتورة الإلكترونية | ✅ |
| التقرير اليومي (X/Z) بطباعة حرارية | ✅ |
| المنيو الذكي العام بـ QR | ✅ |

## خارج النطاق (تحتاج اتفاقيات أو أجهزة خارجية)

- الربط الفعلي (API) مع جاهز وهنقرستيشن وسلة وقيود وبونات ولويا برو: طرق الدفع والقنوات مسجلة للتتبع والتقارير، والربط البرمجي يحتاج مفاتيح الشركاء.
- أجهزة الدفع ECR (جيديا/مدى): تحتاج SDK الجهاز.
- شاشات VFD التسلسلية، التصنيع، الجيم، الخياطة.
