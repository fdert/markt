# رصيد — نظام نقاط البيع والمخزون والمحاسبة

نظام متكامل للمتاجر السعودية: كاشير بقارئ الباركود، فواتير متوافقة مع الفوترة الإلكترونية (زاتكا)، مخزون متعدد الفروع، مشتريات ومصروفات، محاسبة بالقيد المزدوج، وتقارير لحظية. الواجهة عربية بالكامل ومن اليمين إلى اليسار.

## المزايا الرئيسية

| الوحدة | ما تقدمه |
|---|---|
| **نقطة البيع** | قارئ باركود (يعمل دون الضغط على حقل البحث)، باركود الميزان، الوحدات المتعددة، الباركود المكرر، فحص السعر، الخصم والكوبون ونقاط الولاء، الدفع المتعدد (نقدي/شبكة/تحويل/آجل)، تعليق الفواتير، بيع الموظف بسعر التكلفة، الصرف الداخلي، اختصارات F2–F10 |
| **الورديات والصندوق** | فتح الوردية، إضافة نقد ومصروف، الإغلاق بالعد الفعلي وحساب الفرق، طباعة كشف الوردية، مراجعة الصناديق |
| **الطباعة** | إيصال حراري 80/58 مم، فاتورة A4 ومختصرة، طباعة عبر المتصفح أو **مباشرة** (USB / منفذ تسلسلي / مساعد طباعة محلي / طابعة شبكة) مع **قص الورق وفتح درج النقود** |
| **الفوترة الإلكترونية** | رمز QR للمرحلة الأولى (TLV)، فاتورة UBL 2.1، سلسلة البصمات (PIH) والعداد (ICV)، التوقيع ECDSA ‏secp256k1، ربط الفروع ببوابة فاتورة (OTP ← الامتثال ← الإنتاج)، الإبلاغ والاعتماد مع إعادة المحاولة |
| **الفواتير** | مبسطة وضريبية، مسودات وعروض أسعار، المرتجع الجزئي والكلي (إشعار دائن)، تحصيل الآجل، تصدير Excel، تنزيل XML، مشاركة واتساب |
| **المنتجات والمخزون** | بسيط، احترافي، خدمة، إيجار، منتج موزون، منتج مركّب (وصفة)، وحدات وباركود لكل وحدة، مخزون لكل فرع، بطاقة الصنف، التسوية والجرد، التحويلات بين الفروع، اقتراحات الشراء، الصلاحية |
| **العملاء** | أفراد ومنشآت، الرقم الضريبي والعنوان الوطني، المستحقات، نقاط الولاء، سجل الفواتير |
| **المشتريات والمصروفات** | الموردون، فواتير الشراء ومرتجعاتها مع **متوسط التكلفة المرجّح**، السداد، المصروفات وضريبة المدخلات |
| **المحاسبة** | دليل حسابات، قيود آلية لكل عملية، قيد يدوي، ميزان المراجعة، قائمة الدخل، الميزانية، **إقرار ضريبة القيمة المضافة**، إقفال الفترات، صحة الحسابات |
| **التسويق** | الكوبونات (نسبة/مبلغ/حدود/قنوات)، العروض (نسبة، مبلغ، اشترِ X واحصل على Y، التشكيلة) |
| **عقود الإيجار** | تأجير بسعر زمني مع تأمين مسترد وإرجاع للمخزون |
| **التقارير** | 17 تقريراً: ملخص المبيعات، الأفضل مبيعاً، طرق الدفع، الفروع، التصنيفات، الكاشير، الذروة، العملاء، أعمار الذمم، المرتجعات، العروض، المخزون، فجوة التكلفة، المشتريات، المصروفات، الأرباح |
| **الإعدادات** | بيانات المتجر، قوالب الفواتير بمعاينة حية، خيارات الكاشير، الضريبة، الفروع والمستودعات، الموظفون وصلاحيات دقيقة (26 صلاحية) تُفحص في الخادم، الاستيراد من Excel/CSV، سجل الأحداث |

## التقنيات

- **الخادم:** Node.js 22 + Express 5 + TypeScript + Drizzle ORM + PostgreSQL 16، تحقق المدخلات بـ Zod، مصادقة JWT.
- **الواجهة:** React 18 + TypeScript + Vite + Tailwind CSS + TanStack Query، خط Tajawal، RTL كامل.
- **الاختبارات:** Vitest + Supertest (اختبارات تكامل لمسار البيع والمحاسبة والفوترة الإلكترونية).
- **النشر:** Docker Compose + Nginx + Let's Encrypt على Hostinger VPS، مع GitHub Actions.

```
raseed/
├── api/                 الخادم (Clean Architecture: routes → services → db)
│   ├── src/db/          مخطط قاعدة البيانات
│   ├── src/services/    منطق الأعمال: التسعير، المبيعات، المخزون، المحاسبة، زاتكا
│   ├── src/routes/      واجهات REST
│   ├── drizzle/         ملفات الترحيل
│   └── test/            الاختبارات
├── web/                 الواجهة
│   ├── src/features/pos     الكاشير
│   ├── src/features/print   محرك الطباعة (HTML + ESC/POS)
│   └── src/pages            الصفحات
├── tools/print-agent    مساعد الطباعة المحلي لأجهزة الكاشير
├── deploy/              سكربتات Hostinger VPS والنسخ الاحتياطي
└── .github/workflows    التكامل والنشر المستمر
```

## التشغيل محلياً

```bash
# 1) قاعدة البيانات (PostgreSQL 16)
createdb raseed

# 2) الخادم
cd api
cp .env.example .env          # عدّل DATABASE_URL و JWT_SECRET
npm install
npm run db:migrate            # إنشاء الجداول
npm run seed                  # بيانات تجريبية (اختياري)
npm run dev                   # http://localhost:4000

# 3) الواجهة
cd ../web
npm install
npm run dev                   # http://localhost:5173
```

بيانات الدخول التجريبية بعد `npm run seed`:
- المالك: `owner@raseed.sa` / `Raseed@123`
- الكاشير: `cashier@raseed.sa` / `Raseed@123`

بدون بيانات تجريبية: افتح الواجهة وسيظهر لك **إعداد المتجر** لإنشاء حساب المالك.

## الاختبارات

cd api && npm test     # تُنشئ قاعدة raseed_test تلقائياً

## النشر على Hostinger VPS

1. أنشئ VPS بنظام Ubuntu 22.04 أو 24.04، ووجّه النطاق (سجل A) إلى عنوان IP الخادم.
2. ادخل للخادم عبر SSH ونفّذ:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/<USER>/raseed/main/deploy/hostinger-setup.sh -o setup.sh
   sudo bash setup.sh https://github.com/<USER>/raseed.git pos.example.sa admin@example.sa
   ```
   يثبّت السكربت Docker وNginx وشهادة SSL، ويولّد كلمات سر قوية في `/opt/raseed/.env`، ويشغّل النظام، ويجدول نسخة احتياطية يومية.
3. افتح `https://pos.example.sa` وأنشئ حساب المالك.

### النشر التلقائي بعد كل دفع إلى GitHub

أضف هذه الأسرار في المستودع (Settings ← Secrets and variables ← Actions):

| السر | القيمة |
|---|---|
| `VPS_HOST` | عنوان IP للخادم |
| `VPS_USER` | مستخدم SSH (مثل root) |
| `VPS_SSH_KEY` | المفتاح الخاص لـ SSH |
| `VPS_PORT` | منفذ SSH (اختياري، الافتراضي 22) |

كل دفع إلى `main` يشغّل الاختبارات والبناء، ثم ينشر تلقائياً عبر `deploy/deploy.sh` (نسخة احتياطية ← سحب ← بناء ← ترحيل).

### الفروع في Git

- `main` الإنتاج — يُنشر تلقائياً.
- `dev` التطوير.
- `feature/*` لكل ميزة جديدة، ثم طلب دمج إلى `dev`.

### النسخ الاحتياطي والاستعادة

```bash
bash deploy/backup.sh                                        # يدوياً
bash deploy/restore.sh /opt/raseed-backups/raseed-XXXX.sql.gz
```

## إعداد الطابعة الحرارية

من نقطة البيع: **⚙ إعدادات الطباعة**. الطرق المتاحة:

1. **عبر المتصفح:** لأي طابعة. اضبط حجم الورق 80 مم وألغِ الهوامش.
2. **مباشرة عبر USB أو المنفذ التسلسلي** (Chrome/Edge): طباعة فورية مع القص وفتح الدرج.
3. **مساعد الطباعة المحلي** (`tools/print-agent`): لطابعات Windows المثبتة أو طابعة شبكة `IP:9100`.

تُرسم الفاتورة صورةً نقطية قبل إرسالها، فتظهر العربية صحيحة على كل طابعات ESC/POS.

## الفوترة الإلكترونية (زاتكا)

- **المرحلة الأولى:** تعمل تلقائياً عند إدخال الرقم الضريبي — كل فاتورة تحمل رمز QR.
- **المرحلة الثانية:** الإعدادات ← ضريبة القيمة المضافة ← ربط الفرع: أدخل رمز OTP من بوابة فاتورة، ثم شغّل فحص الامتثال، ثم أكمل الربط. ابدأ بـ **بيئة المطورين** للتجربة قبل الإنتاج.

> ملاحظة: التوقيع والإرسال مبنيان على مواصفات الهيئة، ويجب اجتياز فحص الامتثال في بيئة المطورين قبل التحول للإنتاج.
