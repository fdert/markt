# مساعد الطباعة المحلي

برنامج صغير يعمل على جهاز الكاشير، يستقبل الإيصالات من نظام رصيد ويرسلها مباشرة إلى الطابعة الحرارية دون نافذة طباعة، مع **قص الورق** و**فتح درج النقود**.

## التشغيل

1. ثبّت Node.js (الإصدار 18 أو أحدث).
2. شغّل: `node agent.mjs`
3. في نقطة البيع: **إعدادات الطباعة ← مساعد الطباعة المحلي ← تحديث الطابعات** واختر الطابعة.

## أنواع الطابعات المدعومة

| النوع | ما تكتبه في اسم الطابعة |
|---|---|
| طابعة Windows (USB) | اسمها كما يظهر في Windows |
| macOS / Linux (CUPS) | اسمها في `lpstat -a` |
| طابعة شبكة | `192.168.1.50:9100` |

## التشغيل التلقائي مع Windows

أنشئ اختصاراً لملف `start-agent.bat` داخل مجلد بدء التشغيل (`shell:startup`).

## متغيرات اختيارية

- `RASEED_AGENT_PORT` المنفذ (الافتراضي 17777).
- `RASEED_ALLOWED_ORIGINS` نطاقات النظام المسموح لها، مثل `https://pos.example.sa`.
